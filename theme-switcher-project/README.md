# Local Business Directory

## Description

This project is a simple local business directory created using HTML, CSS and JavaScript.

The page displays different types of local business  such as coffee shops and restaurants.

## Features

- Displays local businesses
- Has a light mode and dark mode
- A button allows the user to switch between the two modes
- The button text changes depending on the current mode
- JavaScript is used to manipulate the DOM

## What I learned 

Through this project I learned how to use JavaScript to:

- Find HTML elements using `getElementById()`
- Listen for user clicks using `addEventListener()`
- Add and remove CSS classes using `classList.toggle()`
- Check whether a class exists using `classList.contains()`
- Change HTML text using `textContent`
