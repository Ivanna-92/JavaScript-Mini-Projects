# JavaScript Mini Projects

A collection of JavaScript mini-projects created while practising core JavaScript concepts, DOM manipulation, APIs, AJAX, async/await, and HTTP requests.

## Projects

- **AJAX Project** — Practice using AJAX requests to retrieve and display data.
- **Array Project** — Practise working with JavaScript arrays and array methods.
- **Async Await Project** — Practise handling asynchronous JavaScript using async/await.
- **Basic Calculator** — A simple calculator using JavaScript calculations and event handling.
- **GET POST Project** — Practise making GET and POST requests and handling responses.
- **GET Query Project** — Practise sending query parameters with GET requests.
- **HTTP Error Project** — Practise handling HTTP errors and displaying appropriate messages.
- **Image Gallery** — A JavaScript image gallery demonstrating DOM manipulation and event handling.
- **Math Calculator Project** — Practise mathematical calculations using JavaScript.
- **Name Greeting Project** — A simple project that takes a name and displays a personalised greeting.
- **POST Form Handling** — Practise handling form data and sending POST requests.
- **PUT PATCH Project** — Practise using PUT and PATCH HTTP requests to update data.
- **Task List Project** — A task management project using JavaScript and DOM manipulation.
- **Theme Switcher Project** — Practise changing between different page themes using JavaScript.
- **To-Do List Project** — A simple to-do list demonstrating DOM manipulation, events, and JavaScript logic.

## Concepts Practised

This collection covers a range of JavaScript concepts, including:

- Variables and data types
- Arrays and array methods
- Functions
- Conditional statements
- Loops
- Events and event listeners
- DOM manipulation
- Objects
- Fetch API
- AJAX
- JSON
- HTTP requests
- GET, POST, PUT and PATCH requests
- Error handling
- Promises
- Async/await
- Working with APIs

## Purpose

These projects were created as practical exercises while learning JavaScript. Each project focuses on different concepts and helps build confidence through hands-on practice.
